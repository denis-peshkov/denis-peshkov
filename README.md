### About

I design and ship production-grade .NET platforms: CQRS pipelines, identity, caching, messaging, observability, and the glue that keeps microservices honest.

- Architecting systems end-to-end — from domain boundaries to CI/CD and NuGet packaging  
- Building reusable libraries used across products (the **Cross.*** ecosystem)  
- Consulting on architecture, performance, and maintainable delivery  
- Prefer code that is typed, testable, and boring in production  

📍 **Kyiv, UA** · 🏢 **[GURU SOLUTIONS](https://gurusolutions.co)** · 🌐 **[peshkov.biz](https://peshkov.biz)**
